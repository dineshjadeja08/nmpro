# Feature and reuse matrix

Classification means proposed NammaPros treatment, not a claim that Purple Squad is deployed or complete. B/F denote archive roots defined in `01_REPOSITORY_AUDIT.md`. Tests named are static test files; none were run. `REUSE` is limited to low-risk patterns/helpers after license and behavior review. Endpoint paths are relative to `/api/v1/`. Each row names the main source, API/model, test evidence, limitation and decision.

| Feature | Evidence, dependencies, limitation and disposition |
|---|---|
| Homepage/discovery/search | F `src/app/page.tsx`, `services`, `search`; B `apps/catalogue/views.py`, `models.ServiceCategory/Service`; GET `service-categories/`, `services/`; `tests/test_catalogue.py`. Purple Squad branding and route-specific pages: **REBUILD UI**, **REFACTOR API**. |
| Location/address | F `features/addresses`, `features/location`; B `apps/locations`; GET `service-areas/check/`, geocode; `addresses/`; `Address`, `ServiceArea`; `tests/test_locations.py`, `test_location_lookup.py`. Postal-only serviceability and external map dependency: **REFACTOR**. |
