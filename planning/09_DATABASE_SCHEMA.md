# Proposed PostgreSQL schema

Existing model evidence: `B/apps/accounts/models.py`, `catalogue/models.py`, `locations/models.py`, `scheduling/models.py`, `bookings/models.py`, `payments/models.py`, `technicians/models.py`, `operations/models.py`. Existing money uses Decimal (`B/apps/bookings/models.py:35-82`); NammaPros uses signed 64-bit integer paise. This is a proposed independent schema, not a migration script.

## Status and transactional rules

Booking states: DRAFT, AWAITING_PAYMENT, CONFIRMED, CONFIRMED_UNPAID, ASSIGNED, EN_ROUTE, ARRIVED, IN_PROGRESS, COMPLETED, CLOSED, CANCELLED, EXPIRED, REFUND_PENDING, REFUNDED. Quote: ACTIVE/EXPIRED/ACCEPTED/REJECTED. Hold: ACTIVE/CONSUMED/EXPIRED/RELEASED. Payment: CREATED/PENDING/CAPTURED/FAILED/REFUND_PENDING/REFUNDED. Assignment: OFFERED/ACCEPTED/DECLINED/ENDED. Staff transitions use compare-and-swap `version` and actor grants.

Transactions: hold creation locks slot counter and expires stale holds; booking creation locks hold, quote and slot and writes booking/event/outbox; payment capture locks intent/booking, deduplicates provider IDs and writes balanced journal; assignment locks booking and technician schedule and enforces partial unique active assignment; quotation acceptance locks version and creates change order; payout creation locks eligible ledger entries so no duplicate settlement. Provider calls occur outside these transactions.

Indexes: `(user_id,created_at DESC)` bookings, `(zone_id,start_at,status)` slots, `(slot_id,state,expires_at)` holds, `(booking_id,created_at)` events, `(technician_id,status,assigned_at)` assignments, `(status,sla_at)` tickets, `(processed_at,available_at)` outbox, `(provider_event_id)` payment events. Use monthly partitions for audit/outbox only after volume justifies them. Enforce FK, uniqueness and check constraints in DB. Retention proposal: payment/ledger/invoice as legally required (validate with counsel); KYC shortest legal period, private and deletable; raw webhook body short encrypted retention; operational logs 90 days; analytics de-identified. Confirm Indian tax, privacy and deletion obligations before production.
